# Revised causal-criteria prompts in neuropathic SMC-active

This study evaluates only the new-prompt condition on the archived 20-node neuropathic dataset. It uses n=200 and n=1000, ten paired data seeds, stated confidence and consistency confidence, and Group I / Group II / their union. Group I has 380 directed-edge and 190 adjacency predicates; Group II has 380 canonical ancestry predicates. All 120 trajectories use 100 distinct attempted questions and save posterior checkpoints at 10, 20, 50, and 100. Abstentions count toward the budget and leave the posterior unchanged. These are trajectory prefixes, without extra terminal mutation at earlier checkpoints.

The ancestry responses are imported from the audited new-prompt Qwen3.5-9B API experiment. Direct-edge and adjacency responses are newly cached using the same pinned DeepInfra BF16 endpoint through OpenRouter, temperature zero, reasoning disabled, 256 output tokens, and the original per-confidence-method seeds. Four concurrent requests share a cooldown: respect `Retry-After`, otherwise start at 30 seconds and double to a maximum of 300 seconds, with at most 20 transport attempts per request. Transport failures halt with an incomplete, resumable cache; they are not expert abstentions. New requests have a $1 spending cap including conservative unresolved reservations. Imported source costs are reported separately.

For each consistency question, four affirmative phrasings and two label orders produce eight requests. At least six must be valid binary answers. Ties return NO at confidence 0.5; otherwise confidence is max(0.5, (majority count + 0.5)/9). Stated confidence is the probability that the selected answer is correct; a valid abstention is accepted immediately, and malformed output gets one retry. Justifications are retained for audit only. All accepted answers enter inference as soft evidence, capped at effective confidence 0.99.

The complete prompt templates are frozen in `prompts.json` in each timestamped run. The direct-edge question asks whether X directly causes Y, and requires a specific direct mechanism for YES. The adjacency question asks whether X and Y are directly causally related in either direction; YES requires a direct mechanism in at least one direction, and NO requires support for absence of an edge in both directions. Both explicitly state that an indirect pathway alone does not establish a direct edge, distinguish association from causation, and allow abstention. The ancestry templates and imported raw requests must reproduce exactly before any new paid requests are made.

Inference reuses the archived observations, 384-particle PC+GES initial populations, and stable inference seeds. There are no additional initialization moves. The score is BDeu with equivalent sample size and structure prior one and at most 12 parents. Acquisition uses EIG with working confidence 0.9; resampling threshold is ESS 192. Mutation uses two proposals per particle after resampling or a valid answer at terminal slot 100, guided mixture probability 0.5, uniform-pair ordinary proposals, and cache size 256. The paper's final-answered-question wording differs when slot 100 abstains: this study explicitly preserves the archived implementation's lack of terminal mutation in that case.

The cache is completely reconstructed offline and audited before inference. Seed-zero runs at both sample sizes undergo twelve deterministic offline replays before the remaining seeds run. Acquisition receives only the response to its selected question; ground truth is used for evaluation only. No network access is permitted during inference or reporting.

Reports include structural mean and standard error over ten data seeds, pooled selected-answer accuracy/Brier, coverage, abstentions, claim-type counts, request/token counts, timing, and actual API spending. Paired contrasts use nominal 95% bootstrap intervals with 10,000 resamples over available paired seeds; undefined calibration values remain missing. These intervals condition on the cached model responses. Historical comparisons use archived matching checkpoints and are descriptive because both prompting and provider changed; there is no matched old-prompt API inference control.

Run or resume with an exported `OPENROUTER_API_KEY`:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python code/scripts/run_neuropathic_new_prompt_smc.py --run-id YYYYMMDDTHHMMSSZ --stage run
```

`prepare`, `pilot`, `fill`, and `audit` stages are also available. The `run` stage completes and audits the cache, then starts the gated offline workflow with automatic continuation and reporting. Results live under `results/<timestamp>/neuropathic_new_prompt_smc/`, and logs under `out/<timestamp>/neuropathic_new_prompt_smc/`. `status.json` records cache progress; per-block status and submission records track inference. If a previously submitted compute job fails, use the submission script for the failed phase to resume missing blocks after addressing its failure.
