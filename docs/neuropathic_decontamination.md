# Neuropathic benchmark decontamination study

This audit tests language-model-assisted causal discovery after removing the published benchmark's recognizable variable names.

## Locked benchmark

The experiment uses the 20-node ancestor-closed subnetwork from the locked Table 5 benchmark kit. It evaluates data seeds 0 through 9 at 200 and 1,000 observational samples. The 200-sample dataset is the first 200 rows of the corresponding 1,000-sample dataset. The target DAG is evaluation-only and is never exposed to a discovery method or model prompt.

A fixed permutation generated with NumPy seed 2027 maps source columns to `V01` through `V20`. Model-facing metadata contains only these opaque identifiers and concise English clinical descriptions. Prompts may describe the domain as a clinical diagnostic system, but may not contain an original variable name, the benchmark name, or the phrase identifying the published disease model. Saved requests are audited before aggregation. The audit distinguishes externally supplied system and user text from model-generated assistant history. Protected terms in supplied text fail the run, while protected terms generated by the model are retained and reported as a diagnostic of possible memorization.

The Terra run imports the model-independent GES particle initializations from the completed preparation run. It also imports the completed gPC-Guess, BFS+Pearson, and stated-confidence Claim-Fuse records. Dataset, statistics, record, summary, and prompt-audit hashes are validated before reuse.

## Compared methods

- gPC-Guess uses one GPT-5.6 Terra skeleton guess per data seed, a chi-squared conditional-independence test, and significance level 0.05. The guess is shared across the two nested sample sizes.
- BFS+Pearson uses GPT-5.6 Terra with the statistical sequential-query variant and temperature 0.7.
- Claim-Fuse-SMC-Active uses 20 actively selected Group I claims, soft evidence with an effective confidence cap of 0.99, GES-only initialization, BDeu equivalent sample size 1, structure prior 1, 384 particles, and 192 initialization updates per particle. It is evaluated with stated confidence, semantic consistency, and document-grounded confidence. Semantic consistency uses eight independently phrased judgments and requires at least six valid responses. Document-grounded confidence restricts evidence to four prespecified clinical reviews and requires cited support from retrieved passages.

SCP and Long are excluded because their native protocols require token log probabilities, which GPT-5.6 Terra does not expose through OpenRouter. Causal Order is excluded because its 1,140 triplet requests make it disproportionately expensive for this audit.

All model calls use `openai/gpt-5.6-terra` through OpenRouter with reasoning effort set to `none`. Exact requests and responses are stored in separate run-local caches for semantic consistency and document-grounded confidence. Each strategy stops before issuing a request that could exceed its fixed $5 incremental cost cap, and the combined extension is capped at $10.

## Outputs

Each new confidence strategy first evaluates the seed-0, 200-sample pilot and audits its saved prompts, then resumes the remaining conditions from the same strategy-specific cache. The complete result contains 100 method-condition records, including 60 imported locked records and 40 new Claim-Fuse records. Graph-recovery aggregates report mean and standard error over ten data seeds for expected distance, energy score, adjacency F1, and orientation F1. Confidence-quality aggregates pool the 200 selected query events per sample size and strategy, report coverage over all query slots, and compute accuracy, Brier score, and ten-bin expected calibration error over valid responses only. Aggregation fails if a record is missing or duplicated, a saved request fails the contamination audit, an unexpected response model is observed, or incremental recorded cost exceeds $10. Reported and effective confidence, requests, tokens, retries, cache hits, latency, and cost remain available in the run artifacts.

## Qwen3.5-9B extension

The Qwen extension uses the pinned `Qwen/Qwen3.5-9B` revision `c202236235762e1c871ad0ccb60c8ee5ba337b9a` with thinking disabled. It references the same 20 opaque observational datasets and model-independent statistics as the Terra evaluation, with every input validated by SHA-256. Its eight rows per sample size are gPC-Guess, SCP Pattern 2, BFS+Pearson, Causal Order+PC, PC+Long-Srisk, and Claim-Fuse-SMC-Active with stated, semantic-consistency, or document-grounded confidence.

The baseline protocols are locked before evaluation. gPC-Guess uses a chi-squared test at level 0.05. SCP Pattern 2 uses 1,000 PC bootstraps, all 380 ordered pairs per condition, one explanation and five first-token log-probability judgments per pair, temperature 0.7, and thresholds 0.05 and 0.95. BFS includes Pearson correlations and enforces opaque identifiers in every answer. If BFS returns no root variable, the trajectory is retained and scored as an empty graph rather than retried or excluded. Causal Order queries all 1,140 triplets once, applies a 95 percent parsing gate, and combines the shared order with PC at level 0.01. Long uses S-risk, tolerance 0.1, and at most 50,000 exact MEC extensions. Claim-Fuse uses the same settings and algorithmic random seeds as the Terra comparison.

A non-reportable smoke gate runs on real opaque inputs before the full evaluation. It exercises a full 20-node gPC guess, 16 SCP ordered pairs with the complete six-call probability protocol, a three-node BFS conversation, one causal-order triplet, one Long comparison, and one active SMC update under each confidence strategy. The full evaluation cannot start unless the pinned model identity, parsers, probabilities, graph validity, normalized particle distributions, and prompt-contamination audit all pass. Full aggregation then requires exactly 160 unique method-condition records, independently recomputes every saved graph metric, verifies 20 Claim-Fuse queries per trajectory, and reports mean and standard error over the ten data seeds. The paper is updated only after this aggregate passes.
