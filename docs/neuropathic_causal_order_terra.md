# Terra Causal Order+PC on Table 2

The dedicated experiment uses all 1,140 triplets of the frozen 20-node neuropathic subnetwork. One expert collection is shared across ten observation seeds at n=200/1000. Stable PC uses the G² test at alpha 0.01, collider rule zero, and conflict priority two. Frozen observations and PC outputs are verified against the historical benchmark before collection.

The run preserves the exact archived Table 2 Causal Order messages, including the full 20-node clinical glossary. These differ from the newer SMC prompts in Figure 3. The provider is OpenRouter's pinned OpenAI endpoint for `openai/gpt-5.6-terra`, without routing fallback, with reasoning disabled and request seed zero. Temperature is omitted because that endpoint does not support the parameter. Triplets allow 4,096 output tokens and one parsing retry at 7,680; tie-breaks allow 2,048 tokens and PC fallbacks 256. At least 95% of triplets must parse. The pinned voting, cycle removal, and order integration remain unchanged.

Graph responses and A/B/C tie-break responses are parsed separately. The earlier Qwen replay mistakenly treated A/B/C as malformed graph answers. Before collecting Terra answers, the experiment reproduces the historical Qwen expert and all twenty graphs, then reports the effect of correcting this parser separately. Historical artifacts and the paper remain unchanged. A valid C answer is allowed for a voting tie, but a PC fallback must orient an existing adjacency. Invalid fallbacks and cyclic integration are reported as infeasible; no complete-case aggregate replaces the full benchmark.

The CLI is `python -m cd_llm.experiments.neuropathic_causal_order_terra STAGE --run-id TIMESTAMP`. Stages are `prepare`, `pilot`, `collect`, `audit`, `integrate`, `report`, and `submit`; `finish` combines the final offline stages. Submission chains preparation, collection, and final reporting. Collection resumes from the same cache after a time checkpoint. A failed validation or exhausted spending limit stops the chain.

The twenty-triplet pilot covers every node without using target labels. The total $25 API cap includes pilot calls, malformed responses, repairs, and transport attempts. Four workers reserve costs immediately before dispatch; unresolved attempts retain conservative reservations across restarts. Request identities include complete messages, model, provider, seed, reasoning configuration, and output limit. Never remove the attempt ledger to resume collection.

Artifacts are under workspace `results/<timestamp>/neuropathic_causal_order_terra/`, with execution logs under the corresponding `out/` timestamp. `status.json` records progress and expenditure. Final artifacts include per-seed graphs and raw ED/ES/F1 metrics, paired-condition comparison tables, accounting and cache audits, and a Table 2-ready row. Every dataset is assigned the full token cost of its required shared responses, including its own PC fallbacks; actual API purchases are counted only once. Unknown token usage associated with unresolved requests is explicitly identified. Standard errors across observation seeds are conditional on the single shared expert collection.
