# Terra SMC with a 0.8 confidence cap

This experiment matches the updated Qwen Table 2 protocol: the same 20-node neuropathic observations, ten seeds at n=200/1000, frozen prompts, and 384-particle PC+GES initializations. It collects fresh Terra answers for local, ancestry, and mixed pools under stated and consistency confidence. The API uses the pinned OpenAI endpoint, reasoning disabled, request seed zero, and 256 output tokens; temperature is omitted because the endpoint does not support it.

The answer bank contains 1,900 outcomes for 950 queries, with 8,550 nominal responses plus repairs and retries. Collection uses four concurrent requests and a durable $25 spending ledger; unresolved attempts retain reservations across restarts. The fixed pilot covers two questions of each claim type under both strategies. An explicit abstention is a parseable response. Consistency requires six valid votes out of eight, with the same pooling rule as Qwen.

Inference clips answer confidence to 0.8 before weighting and MH while preserving the raw value in the audit. EIG working confidence remains 0.9. Each of 120 trajectories has 100 distinct attempted questions including abstentions, with saved posterior checkpoints at 10, 20, 50, and 100. Checkpoints do not trigger extra mutation. Abstentions leave the posterior unchanged, including at attempt 100.

The CLI is `python -m cd_llm.experiments.neuropathic_terra_smc STAGE --run-id TIMESTAMP`, where STAGE is `prepare`, `collect`, `audit`, `run-block`, `validate-pilot`, `report`, or `submit`. A block uses `--block 0` through `--block 19`. Submission chains the validation gates automatically. Collection checkpoints before its deadline and resumes with the same cache and ledger. Budget exhaustion or a failed gate stops dependent work. Never delete the spending ledger to resume.

Artifacts are under workspace `results/<timestamp>/neuropathic_terra_smc/`, with command logs under the corresponding `out/` timestamp. Preparation freezes sources and implementation hashes; model responses are not imported from older protocols. Inference and reporting have network access disabled. Reports require all 120 trajectories and 480 checkpoints, and include raw ED/ES, graph F1 scores, token expenditure, and calibration using both raw and capped confidence. Structural means and standard errors are across ten seeds; confidence diagnostics pool valid answers. Bootstrap differences use 10,000 paired seed resamples, conditional on the shared expert collection. Token expenditure charges all required responses per dataset, without amortizing cache reuse. Actual API purchases and unresolved reservations are reported separately.

The experiment produces six Table 2-ready rows but does not modify the paper or figures.
