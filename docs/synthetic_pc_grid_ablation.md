# PC grid initialization and soft expert ablation

Use the existing synthetic benchmark's ten common-complete SCMs (indices 1, 2, 7, 12, 15, 34, 36, 40, 45, 47), with one observation seed per SCM and nested sample sizes 200 and 1000. The PC significance grid is 0.01, 0.05, 0.10. Load the archived data-only completion probabilities, never the posterior incorporating historical passive claims. Equal configuration mass and duplicate-graph aggregation are inherited from this archived initialization. Deterministically allocate 384 particle slots once per SCM/sample size and share them across conditions; there are no additional initialization moves.

Cross actual expert accuracy 0.6, 0.8, 1.0 with Group I, Group II, and their union. Acquisition uses EIG. Group I contains 380 directed and 190 adjacency questions; Group II contains 380 ancestry questions. Order complements are represented by ancestry, so the union contains 950 distinct questions. Responses retain the truth independently with the specified probability and flip otherwise. A fixed random field indexed by SCM, sample size, and predicate shares response draws across conditions. Both positive and negative answers enter as explicit soft evidence. Reported confidence equals accuracy and effective confidence is capped at 0.99. This compares accuracy/confidence regimes rather than isolating either factor.

Each condition runs to 50 questions, retaining checkpoints 5, 20, and 50. Gaussian BIC, parent cap 12, ESS threshold 0.5, ordinary uniform-pair proposals, guided probability 0.5, and proposal cache size 256 are fixed. Each resampling event and the last query trigger two MH proposal attempts per particle. Intermediate checkpoints do not force mutation, so computation can differ across conditions. Inference seeds are paired across accuracy and claim group. There are 180 trajectories, 540 checkpoint results, and 20 shared zero-query controls.

The command `python -m cd_llm experiment synthetic-pc-grid-ablation` accepts `--stage prepare|compute|aggregate`, `--run-id YYYYMMDDTHHMMSSZ`, and `--task-index` for compute. Prepared inputs and implementation hashes are immutable within a run. Completed trajectories are validated before reuse; incomplete grids cannot produce final aggregate results.

Report mean and standard error over ten SCMs for ED, ES, adjacency F1, and orientation F1. Paired descriptive intervals use 10,000 SCM-level bootstrap resamples, without multiplicity correction, for all claim-group pairs and each group versus initialization. Archive distributions and query traces, actual response accuracy, confidence semantics, entropy, mutation effort and acceptance, graph-mass ESS, and runtime. The figure has one page per recovery metric and six panels for sample size and expert accuracy. Existing paper figures and results remain unchanged.
